# Counterfeit Drug Detection Model
* Project name: A rapid, effective, and eco-friendly method for identifying counterfeit drugs using NIRS and Machine Learning.

* This repository contains the source code for the model developed for this project. We are deeply honored that this research was awarded 2nd Place at the Vietnam Science and Engineering Fair (ViSEF).
